# 开发面经（最小样本）

## 大文件上传

### 1. 文件切片（Chunking）

大文件上传的核心难点在于网络波动导致的连接中断以及内存溢出。处理的第一步是将文件进行物理切片：

- 使用 `File.slice()` 方法将 `File` 对象切割成固定大小（如 5MB）的 `Blob` 片段。
- 利用并发控制队列将这些切片并行发送给后端。

### 2. 生成文件唯一标识（Hash）

为了让后端识别切片的归属，必须计算文件的唯一哈希值（通常使用 MD5）：

- 采用 `spark-md5` 库计算文件哈希。
- 对大文件可采用抽样哈希（首、中、尾）平衡速度与准确性。

### 3. 秒传与断点续传

- 秒传：后端检查文件 Hash 是否已存在，存在则直接返回上传成功。
- 断点续传：后端返回已上传切片索引，前端只上传缺失切片。

### 4. 合并与清理

- 全部切片上传完成后，前端发送合并请求。
- 后端按顺序合并并校验完整性，完成后清理临时切片目录。
