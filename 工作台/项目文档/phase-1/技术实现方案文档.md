Entropy Zero (Phase 1) 技术实现方案 (Vercel + Supabase & 2026 标准版)

1. 总体架构设计 (Full-Stack Serverless)

系统采用全 Serverless 架构，后端逻辑由 FastAPI (Vercel) 与 Supabase (BaaS) 协同完成。

Frontend: React 18 + Vite 8 + Tailwind CSS v4 + shadcn/ui。

Backend (Logic Layer): Python 3.12 + FastAPI (部署于 Vercel Functions)。

Database & Auth: Supabase (PostgreSQL 16+)。

Auth: 直接使用 Supabase Auth 处理注册登录。

DB: 存储原始知识、笔记及复习卡。

AI Service: 独立 FastAPI 服务或 Edge Runtime，调用 GPT-4o/Claude 3.5。

Async Queue: Upstash Redis，用于驱动异步 AI 梳理任务。

2. 后端技术实现 (Python 3.12 + Supabase)

2.1 数据库访问与 ORM

使用 supabase-py SDK 或 SQLAlchemy 2.0。

优势: 利用 Supabase 的 Row Level Security (RLS)。后端查询时，数据库层级会自动校验 user_id，确保数据绝对隔离。

2.2 异步梳理流 (Task Execution)

用户上传 .md -> 文件存入 Supabase Storage。

FastAPI 向 Upstash Redis 发送任务信号。

Vercel Background Worker (Python 3.12) 接收任务 -> 调用 AI 服务解析。

解析结果直接写回 Supabase。

3. 前端技术实现 (Vite 8)

3.1 核心选型

Vite 8: 利用其最新的热更新引擎，大幅提升开发体验。

Supabase Auth UI: 使用 shadcn/ui 封装的登录组件，调用 Supabase 认证接口。

状态同步: 使用 supabase-js 的实时功能，当 AI 梳理完成，页面自动无刷新更新进度。

5. 部署步骤 (Step-by-Step)

第一步：初始化 Supabase

创建一个新的 Supabase 项目。

在 SQL Editor 中运行表初始化脚本（启用 RLS）。

获取 SUPABASE_URL 和 SUPABASE_ANON_KEY。

第二步：配置后端 (FastAPI)

创建 api/index.py 作为 Vercel 入口。

配置 vercel.json 指定 Python 3.12 运行时。

在 Vercel 控制台设置环境变量：AI_KEY, SUPABASE_URL, UPSTASH_REDIS_URL。

第三步：配置前端 (Vite 8)

npm create vite@latest 并选择 React。

安装 supabase-js 和 lucide-react。

运行 npm run build 生成静态资源，Vercel 会自动识别并部署。

7. 2026 技术标准校验

Vite 8: 默认启用模块化预构建，支持 React 19 的新特性。

Python 3.12: 使用 TypedDict 进行复杂的 JSONB 数据校验，确保代码健壮性。

Supabase: 利用其内置的 PostgREST 功能，简单的 CRUD 操作前端可直连数据库，后端仅处理 AI 核心逻辑，极大降低函数运行成本。
