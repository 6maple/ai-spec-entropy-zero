## Why

当前知识处理流程已具备完整的 AI Agent 实现，但默认仍走占位型 deterministic 路径，导致笔记与卡片质量不足，直接影响学习体验与复习效果。现在需要将系统切换到真实 Agent 流程，消除占位输出，并为中文优先路由提供稳定配置与行为约束。

## What Changes

- 默认启用 AI Agent 处理链路，移除任务执行中对占位 deterministic 分支的依赖。
- 将环境配置升级为可运行真实 Agent 的默认模板，明确 `DASHSCOPE_API_KEY` 必需性，并支持本地覆盖配置。
- 优化语言检测采样策略，从大样本降为轻量采样，降低 token 消耗并保持中英文判别稳定性。
- 约束处理结果不得包含“占位”标签、伪造问答和原文截断式 note body，改为结构化 claims 与真实复习卡。
- 明确 worker 执行路径与启动校验行为，使配置缺失时给出可观测告警而非静默退回假数据。
