知识间的关联性在笔记结构中，主要通过 hooks 字段 来承载。它不仅仅是“超链接”，而是一种 带语义方向的关系图谱。

关联的语义类型（relation 枚举）
为了让 AI 能够准确地建立连接，系统定义了固定的关系类型。这比单纯“相关”更利于算法理解和前端渲染。

类型语义前端视觉暗示（森林地图）示例补充 (Extends)新知识是旧知识的细粒度实现或细节展开。分支生长：从旧叶脉长出细枝连接新叶。shallowRef 是对 ref 在高性能场景下的补充。对立 (Conflicts)逻辑矛盾，触发冲突检测挂起流程。红色警示连线，树叶变黄并闪烁。旧笔记说“频繁修改数组没问题”，新笔记说“大数组修改有性能问题”。因果 (Causes)A 是 B 的原因，B 是 A 的结果。箭头指向（从因到果）。因为“深度响应式追踪开销大”，所以“我们需要 Shallow API”。相似 (Similar)不同领域的同构模式。虚线共振连线。Vue 的 shallowRef 与 React 的 useMemo 在“防止不必要更新”上逻辑相似。前提 (Prerequisite)理解当前笔记需要先理解目标笔记。前置锁链：未复习前提笔记时，当前树叶呈灰色。理解 shallowRef 的前提是理解 Vue 响应式 Proxy。
